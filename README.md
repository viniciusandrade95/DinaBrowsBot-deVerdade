# DinaBrowsBot API

This repo exposes a simple retail assistant chatbot over HTTP using FastAPI. The bot can also answer WhatsApp messages via a webhook:

- `POST /chat` – accepts `text`, `tenant_id`, `user_id`, and optional `message_id` JSON fields and returns a reply generated by the bot logic.
- `GET /health` – liveness check for deployments like Railway.
- `GET /webhook` – verification endpoint for the WhatsApp webhook (requires `WHATSAPP_VERIFY_TOKEN`).
- `POST /webhook` – receives WhatsApp messages and replies using the bot before sending the response back through the Meta Graph API.

## Running locally
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Set your model credentials (if unset, the bot will fall back to simple rule-based replies):
   ```bash
   export MODEL_API_KEY=your_key
   export MODEL_BASE_URL=https://llm.lab.sspcloud.fr/api  # or your endpoint
   ```
3. (Optional) Set WhatsApp credentials to enable the webhook reply:
   ```bash
   export WHATSAPP_ACCESS_TOKEN=your_meta_token
   export WHATSAPP_PHONE_NUMBER_ID=your_phone_number_id
   export WHATSAPP_VERIFY_TOKEN=a_secret_for_webhook_setup
   ```
4. Start the server:
   ```bash
   python app.py
   ```

The app binds to `0.0.0.0` on the port specified by the `PORT` environment variable (default `8000`).

When no model credentials are configured, the bot switches to a rule-based flow that answers greetings, store logistics
(hours/address), shipping/returns, stock checks, and rotates guided prompts so conversations keep moving instead of repeating
the same message.

## WhatsApp integration notes
- Outbound replies use Meta's Graph API; set the `WHATSAPP_*` environment variables shown above.
- The webhook expects the standard Cloud API payload shape (`entry -> changes -> value -> messages`).
- Non-message events (like delivery receipts) are ignored.

## CLI demo
If you want to chat via the terminal instead of HTTP, run:
```bash
python main.py
```
This uses the same bot logic while keeping all message handling local to the process.
