# DinaBrowsBot API

This repo exposes a simple retail assistant chatbot over HTTP using FastAPI and also includes a helper module for sending outbound WhatsApp template messages via Meta's Graph API.

## HTTP endpoints
- `POST /chat` – accepts `text`, `tenant_id`, `user_id`, and optional `message_id` JSON fields and returns a reply generated by the bot logic.
- `GET /health` – liveness check for deployments like Railway.

## Running locally
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Set your model credentials:
   ```bash
   export MODEL_API_KEY=your_key
   export MODEL_BASE_URL=https://llm.lab.sspcloud.fr/api  # or your endpoint
   ```
3. Start the server:
   ```bash
   python app.py
   ```

The app binds to `0.0.0.0` on the port specified by the `PORT` environment variable (default `8000`).

## WhatsApp outbound helper
Use `bot.whatsapp.send_template_message` to trigger a WhatsApp template message. Configuration comes from environment variables or keyword overrides:
- `WHATSAPP_ACCESS_TOKEN` – your Meta/WhatsApp API access token.
- `WHATSAPP_PHONE_NUMBER_ID` – the phone number ID from your WhatsApp Business account.
- `WHATSAPP_API_VERSION` – optional Graph API version (defaults to `v22.0`).

Example usage mirrors the cURL snippet you provided:
```python
from bot.whatsapp import send_template_message

response = send_template_message(
    to="<recipient_number_including_country_code>",
    template_name="hello_world",
    language_code="en_US",
)
print(response)
```

The helper raises `WhatsAppConfigError` if required settings are missing and surfaces API errors with the HTTP status and response body.

## CLI demo
If you want to chat via the terminal instead of HTTP, run:
```bash
python main.py
```
This uses the same bot logic while keeping all message handling local to the process.
