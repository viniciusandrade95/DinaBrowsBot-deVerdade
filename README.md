# DinaBrowsBot API

This repo exposes a simple retail assistant chatbot over HTTP using FastAPI. It is intentionally designed **without** any WhatsApp or other messaging platform integration; the only entrypoints are:

- `POST /chat` – accepts `text`, `tenant_id`, `user_id`, and optional `message_id` JSON fields and returns a reply generated by the bot logic.
- `GET /health` – liveness check for deployments like Railway.

## Running locally
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Set your model credentials:
   ```bash
   export MODEL_API_KEY=your_key
   export MODEL_BASE_URL=https://llm.lab.sspcloud.fr/api  # or your endpoint
   ```
3. Start the server:
   ```bash
   python app.py
   ```

The app binds to `0.0.0.0` on the port specified by the `PORT` environment variable (default `8000`).

## Why there is no WhatsApp connection
- The codebase contains no WhatsApp/Twilio/Facebook SDKs or webhooks.
- Incoming traffic is only accepted via the HTTP routes listed above.
- You can layer your own messenger/webhook adapter if needed, but by default the bot runs solely as an HTTP API.

## CLI demo
If you want to chat via the terminal instead of HTTP, run:
```bash
python main.py
```
This uses the same bot logic while keeping all message handling local to the process.
